===========================================================
            AeroPassport - Source Code Directory Guide
===========================================================

The file "AeroPassport_Project_SourceCode.zip" contains the complete
Spring Boot project source code.

-----------------------------------------------------------
1. Main Source Code
-----------------------------------------------------------

Path:

AeroPassport_Project_SourceCode.zip
└── src
    └── main
        └── java
            └── com
                └── aeropassport

Contents:

1. controller
   - Contains all REST Controller classes responsible for handling
     API requests and responses.

2. dto
   - Contains Data Transfer Object (DTO) classes used for request
     and response data transfer.

3. model
   - Contains MongoDB document model (entity) classes.

4. repository
   - Contains Spring Data MongoDB repository interfaces used for
     database operations.

5. service
   - Contains the business logic and service layer implementation.

6. AeroPassportApplication.java
   - Main Spring Boot application class used to start the project.

-----------------------------------------------------------

Path:

AeroPassport_Project_SourceCode.zip

        └── java

-----------------------------------------------------------
Notes
-----------------------------------------------------------

• The "src/main" directory contains the complete application
  source code.

• The "src/test" directory contains the project test files.

• The project follows the standard Spring Boot layered architecture,
  separating Controllers, Services, Repositories, Models, and DTOs.
